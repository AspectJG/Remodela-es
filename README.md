# JGRemodelacoes — Site (branch: site)

Este branch contém um rascunho one-page gerado automaticamente a partir do cartão de visita no repositório.

O que criei:
- index.html — página principal (one-page)
- css/style.css — estilos
- js/main.js — interatividade mínima (menu móvel, lightbox, scroll suave)

Detalhes e próximos passos:
- O logotipo no header usa a imagem existente no repositório em: 1788127725907.png (referenciada via raw.githubusercontent)
- O formulário usa o serviço _formsubmit.co_ apontado para: joaogargaloremodelacoes@gmail.com. Não é necessário backend — quando o formulário for submetido abrirá num separador novo.
- Portefólio está com imagens temporárias (Unsplash). Substitui por fotos reais em assets/ quando disponível.

Deploy no GitHub Pages:
1) No repositório, vai a Settings > Pages
2) Em "Source" escolhe a branch `site` e a pasta `/ (root)`
3) Guarda — o site ficará disponível em: https://AspectJG.github.io/Remodelacoes/ (pode demorar alguns minutos)
